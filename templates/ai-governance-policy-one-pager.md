## 5. Roles and responsibilities

| Role | Responsibility |
|---|---|
| System owner | Maintains the risk assessment; accountable for the system's behaviour in production |
| AI governance function | Maintains this policy; reviews and approves high-risk uses |

| All staff | Use only approved tools; report incidents |

## 6. Risk classification

Every AI use is classified before deployment. Classification determines what's required.

| Tier | Definition | Requirements |
|---|---|---|
| Prohibited | | Not permitted under any circumstances |
| High | | Documented risk assessment, adversarial testing, human oversight, named owner, [cycle] review |
| Limited | | Transparency notice to users, register entry, annual review |
| Minimal | | Register entry only |

## 7. Requirements before deployment

- [ ] Risk classification recorded
- [ ] Risk assessment completed (high-risk only)
- [ ] Adversarial / red-team testing completed (high-risk only)
- [ ] Human oversight mechanism defined and tested
- [ ] Data handling reviewed against privacy obligations
- [ ] Entry added to the AI system register
- [ ] Named system owner assigned
